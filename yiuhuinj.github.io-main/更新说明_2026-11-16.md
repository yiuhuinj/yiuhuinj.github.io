### 建议你手动处理（我无法替你做的）
1. **GitHub Pages 开启强制 HTTPS**：仓库 Settings → Pages → 勾选 "Enforce HTTPS"（站内 `http://` 链接会自动升级）
2. **删除重复证书图**：`classic/certificate.jpg` 与 `classic/cert-new.jpg` MD5 完全相同，删一份可再省约 300KB（删前确认 classic 页面引用的是哪个文件名，只删未被引用的）
3. **简历 PDF 改名**：`2026级物流管理新生简历.pdf` → 建议改为 `李胜飞_简历_川外物流管理.pdf`（更专业；同步改 index.html 第 42 行 dock 里的两处文件名）
4. **Google Fonts 国内加载**：当前走 fonts.googleapis.com，国内访客可能字体加载慢（已有 display=swap 兜底不阻塞渲染，可接受；如追求极致可换国内镜像或自托管 woff2）
5. **能力星图分值口径**：92/100 这类自评分是主观的，求职场景无碍（有实战注解支撑即可），但建议后续给每项能力挂上作品链接（如"AI 应用"指向 zhenhaiguan.html）
6. **classic 正式简历站同步**：正式简历（classic/）里建议也加一段镇海关项目（参赛获奖后尤其重要），并更新 PDF 版本
